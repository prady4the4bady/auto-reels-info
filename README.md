# Auto-reels

Auto-reels is a personal, non-commercial project. It creates short educational videos from public Wikipedia text and uploads them to the project owner's own YouTube channel.

## How it uses Google and YouTube data

- It uses the YouTube Data API only to upload videos to, and read view statistics from, the single YouTube channel owned by the person running it.
- It requests two permissions: upload videos (`youtube.upload`) and read-only access to channel statistics (`youtube.readonly`).
- It has no public sign-in and serves no other users.
- Auto-reels uses YouTube API Services. By using it you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms).

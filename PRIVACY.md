# Privacy Policy for Auto-reels

Last updated: 30 October 2026

Auto-reels is a personal, non-commercial project run by its developer for the developer's own YouTube channel. It has no other users and no public sign-in.

## What data the app accesses

When the developer authorizes the app with their own Google account, the app can:

- upload videos to that account's YouTube channel (`youtube.upload`);
- read statistics for those videos, such as view, like and comment counts (`youtube.readonly`).

## How the data is used

Uploaded videos are published to the developer's own channel. Video statistics are used only to see which videos perform better so that future videos can be improved.

## Storage and sharing

- Google sign-in credentials and tokens are stored only in a private configuration file on the developer's own computer. They are not published, sold, shared or transferred to anyone.
- Video statistics are stored in a local database on the same computer.
- The app does not collect, store or share data about any other person.
- Draft videos, titles and captions are sent to the developer's private Telegram chat for review.
- Public Wikipedia text is sent to a language-model API to help write scripts. The titles and view and like counts of the developer's own videos may also be sent to that API so it can summarise which topics performed better. No other Google user data is sent.

## Google API Services User Data Policy

Auto-reels' use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

Auto-reels uses YouTube API Services and is subject to the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy).

## Revoking access and deleting data

The developer can revoke the app's access at any time at https://myaccount.google.com/permissions and can delete uploaded videos in YouTube Studio. Deleting the local configuration file and database removes all stored credentials and statistics.
